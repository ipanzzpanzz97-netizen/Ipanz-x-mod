MODUL 2: iPANZ DEEP CLEANER (PEMBERSIH STORAN UFS 4.0 & RAM LPDDR5X)
- Fitur 2A: Pembersih Sampah Mendalam (Deep Junk & Residual Cleaner)
  * Kegunaan Fitur: Mengimbas dan membuang fail sampah sebenar seperti baki fail pemasang `.apk`, fail log/sementara (`.tmp`, `.log`), folder kosong, dan sisa cache media aplikasi sosial supaya kelajuan baca/tulis storan UFS 4.0 kekal maksimum.
  * Implementasi Sebenar: Gunakan `MANAGE_EXTERNAL_STORAGE` + Kotlin Coroutines `FileTreeWalk` dengan penapis keselamatan ketat supaya gambar, video peribadi, dan dokumen pengguna TIDAK disentuh. Paparkan senarai fail dan jumlah MB/GB sebenar sebelum dipadam.
- Fitur 2B: Pengesan Fail Pendua & Fail Besar (SHA-256 Duplicate & Heavy File Scanner)
  * Kegunaan Fitur: Mencari fail kembar/pendua yang memakan ruang berganda serta menyenaraikan fail bersaiz besar (>100 MB) untuk semakan pantas.
  * Implementasi Sebenar: Tapis mengikut saiz fail yang sama dahulu, kemudian sahkan menggunakan kiraan cincangan `SHA-256` secara penstriman (buffered stream) supaya pantas dan tidak memakan RAM.
- Fitur 2C: Pembebas RAM LPDDR5X & Pintasan Cache Aplikasi (Smart RAM & App Cache Booster)
  * Kegunaan Fitur: Mematikan proses latar belakang yang membazirkan RAM dan kuota CPU sebelum bermain game, serta membantu membuang cache aplikasi berat.
  * Implementasi Sebenar: Baca memori sebenar melalui `ActivityManager.getMemoryInfo()`, hentikan proses latar aplikasi bukan kritikal menggunakan `ActivityManager.killBackgroundProcesses()` berdasarkan data `UsageStatsManager`, dan sediakan pembersih cache berpandu melalui `StorageStatsManager` + pilihan automasi `AccessibilityService` / Shizuku (jika diaktifkan pengguna).

MODUL 3: iPANZ HYPERGAME ENGINE & FLOATING HUD (MOD PEMACU GAME)
- Fitur 3A: Pengoptimum Pra-Game Satu Sentuhan (iPanz Game Boost Mode)
  * Kegunaan Fitur: Mengoptimumkan keadaan telefon sebelum masuk ke dalam game dengan membersihkan proses latar, mengaktifkan mod Jangan Ganggu (Auto-DND), dan mengunci tahap kecerahan skrin AMOLED supaya skrin tidak malap sendiri ketika tangan menutup sensor cahaya.
  * Implementasi Sebenar: Gunakan API rasmi Android `GameManager`, kawal `NotificationManager` untuk sekat gangguan notifikasi, dan kunci mod kecerahan skrin melalui `Settings.System.SCREEN_BRIGHTNESS_MODE` (`SCREEN_BRIGHTNESS_MODE_MANUAL`). Sediakan senarai pelancar pantas (Game Launcher) untuk game yang dikesan dalam telefon.
- Fitur 3B: Panel Terapung iPanz HUD (Real-Time In-Game Floating Overlay)
  * Kegunaan Fitur: Memaparkan meter prestasi sebenar (FPS, Suhu, Ping) dan butang kawalan pantas secara terapung di atas skrin semasa bermain game.
  * Implementasi Sebenar: Bina `ForegroundService` dengan `WindowManager` (`TYPE_APPLICATION_OVERLAY`) yang boleh dialihkan, dikecilkan menjadi ikon kecil "iPanz", dan tidak mengganggu sentuhan game:
    1. Meter FPS Sebenar: Dikira secara langsung menggunakan `Choreographer.FrameCallback`.
    2. Meter Suhu Sebenar: Bacaan masa nyata daripada `BatteryManager` & `PowerManager.OnThermalStatusChangedListener` dengan penunjuk warna (Hijau < 39°C, Kuning 39-42°C, Merah > 42°C).
    3. Meter Ping Sebenar (ms): Ujian kependaman soket TCP masa nyata ke pelayan 1.1.1.1 / 8.8.8.8 dengan paparan ms tepat.

KONFIGURASI BINAAN GRADLE & JAMINAN SAIZ (70 MB - 95 MB):
1. Dalam `app/build.gradle.kts`:
   - Hadkan ABI kepada `ndk { abiFilters += listOf("arm64-v8a") }` sahaja (optimum sepenuhnya untuk POCO X7 Pro 64-bit dan mengelakkan APK melebihi 100 MB).
   - Tetapkan `packaging { jniLibs { useLegacyPackaging = false } }` dan konfigurasi `aaptOptions { noCompress += listOf("onnx", "ort", "bin") }` supaya fail model suara AI dimuatkan terus ke memori (`mmap`) dengan pantas tanpa ralat kehabisan RAM (`OutOfMemoryError`), sambil mengekalkan saiz APK terkompilasi dalam sasaran 75 MB - 95 MB.
   - Sediakan `proguard-rules.pro` lengkap untuk ONNX Runtime, kelas JNI C++, dan Jetpack Compose supaya binaan Release berjalan lancar tanpa sebarang crash.
